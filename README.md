## Problem Statement
Customers at a small business may experience delays before receiving service. This project explores how workflow changes could reduce waiting times without adding employees.

## Objectives
- Map the current customer-service process.
- Analyze simulated customer arrival and service data.
- Identify potential bottlenecks.
- Compare a proposed process improvement against a baseline scenario.

## Tools
- Google Sheets
- diagrams.net
- Google Docs

## Project Status
In progress — project scope and objectives defined.

## Data and Limitations
This project will use simulated data for educational purposes. Findings will represent modeled scenarios, not verified improvements in a real business.
